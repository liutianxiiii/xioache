# STM32F303K8 四路感光管巡线小车

## 硬件引脚对应

### 感光管（ADC1 + DMA，12位，0~4095）

| 缓冲区下标 | 引脚 | ADC 通道 | 位置 |
|-----------|------|---------|------|
| `adc_buf[0]` | PA0 | IN1 | 最左侧 |
| `adc_buf[1]` | PA1 | IN2 | 左中 |
| `adc_buf[2]` | PA3 | IN4 | 右中 |
| `adc_buf[3]` | PB0 | IN11 | 最右侧 |

DMA 工作在循环模式，自动持续刷新缓冲区，主循环无需手动触发 ADC。

### 电机驱动（TB6612 或同类）

| 电机 | 方向引脚 1 | 方向引脚 2 | PWM 引脚 | 定时器通道 |
|------|-----------|-----------|---------|----------|
| 左轮 Motor A | AIN1 = PF0 | AIN2 = PF1 | PA8 | TIM1_CH1 |
| 右轮 Motor B | BIN1 = PB1 | BIN2 = PA10 | PA9 | TIM1_CH2 |

**PWM 参数**：TIM1，预分频 32，周期 1000 → 频率 = 8MHz / 32 / 1000 = **250 Hz**，CCR 范围 0~1000 对应 0%~100% 占空比。

## 初始化顺序（`main` 函数 `USER CODE BEGIN 2`）

```
HAL_ADCEx_Calibration_Start()   ← 必须在 DMA 启动之前
HAL_ADC_Start_DMA()             ← 启动连续采集
HAL_TIM_PWM_Start(CH1)          ← 使能左轮 PWM 输出
HAL_TIM_PWM_Start(CH2)          ← 使能右轮 PWM 输出
```

> **注意**：原始生成代码中存在三处问题，已在 `main.c` 中修复：
> 1. `adc_buffer` 与 `adc_value` 是两个不同缓冲区，DMA 被重复启动指向不同地址
> 2. ADC 校准在 DMA 启动之后调用（顺序错误）
> 3. `HAL_ADC_Start_DMA` 被调用了两次

## 巡线状态机

### 传感器二值化

```c
uint8_t s = (adc_buf[i] > BLACK_THRESHOLD) ? 1 : 0;
// 1 = 检测到黑线，0 = 白色地面
```

四路状态编码为 4 位值 `[sL  sML  sMR  sR]`：

```
sL   sML   sMR   sR
PA0  PA1   PA3   PB0
最左                最右
```

### 决策表

| 编码（二进制） | 含义 | 左轮 PWM | 右轮 PWM | 动作 |
|--------------|------|---------|---------|------|
| `0110` `0111` `1110` `1111` | 居中 | 600 | 600 | 直行 |
| `0010` | 轻微右偏（仅 sMR） | 680 | 520 | 小幅左转修正 |
| `0011` | 明显右偏（sMR+sR） | 750 | 200 | 中度左转 |
| `0001` | 严重右偏（仅 sR） | 750 | −450 | 急左转 |
| `0100` | 轻微左偏（仅 sML） | 520 | 680 | 小幅右转修正 |
| `1100` | 明显左偏（sL+sML） | 200 | 750 | 中度右转 |
| `1000` | 严重左偏（仅 sL） | −450 | 750 | 急右转 |
| `1001` | T形路口 / 终点 | 600 | 600 | 直行通过 |
| `0000` | 丢线 | 300 | 300 | 低速直行等待找线 |

## 可调参数（`main.c` 顶部宏定义）

| 宏名 | 默认值 | 说明 |
|------|-------|------|
| `BLACK_THRESHOLD` | 2000 | ADC 阈值（0~4095）。高于此值 = 黑线 |
| `SPEED_BASE` | 600 | 直行速度 |
| `SPEED_TRIM` | 80 | 轻微偏差修正幅度，实际速度为 `base ± TRIM`。直线振荡时调小此值 |
| `SPEED_FAST` | 750 | 中度转弯时外侧轮速度 |
| `SPEED_SLOW` | 200 | 中度转弯时内侧轮速度 |
| `SPEED_SPIN` | 450 | 急转弯时反转轮速度 |

## 常见问题排查

### 小车往反方向转
将 `Motor_Drive` 调用中的两个参数对调，或在 `Motor_Drive` 函数内将对应电机的 `xIN1`/`xIN2` 逻辑互换。

### 传感器感应极性相反（白线返回高值）
将 `main.c` 中的阈值比较方向由 `>` 改为 `<`：

```c
// 原来
uint8_t sL = (adc_buf[0] > BLACK_THRESHOLD) ? 1 : 0;
// 改为
uint8_t sL = (adc_buf[0] < BLACK_THRESHOLD) ? 1 : 0;
```

### 速度过快导致冲出跑道
降低 `SPEED_BASE`，同时适当降低 `SPEED_FAST`，保持两者比例不变。

### 丢线后找不回来
增大 `SPEED_BASE / 2` 处的系数，或加入记忆上一次转向方向的逻辑（用一个变量保存上次 `st` 的值）。

## 后续优化方向

- **PID 控制器**：用加权误差 `e = -3·sL - 1·sML + 1·sMR + 3·sR` 替换状态机，P/D 项分别调整直行精度与抖动抑制
- **动态阈值**：上电时扫描传感器最大/最小值，自动计算中间阈值，适应不同光照环境
- **TIM2 定时器**（已初始化，1Hz 周期）：可用于定时调试输出或看门狗喂狗
