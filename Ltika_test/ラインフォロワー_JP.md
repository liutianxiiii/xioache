# STM32F303K8 四センサーライントレースロボット

## ハードウェア ピン対応表

### 光センサー（ADC1 + DMA、12ビット、0〜4095）

| バッファインデックス | ピン | ADCチャンネル | 位置 |
|--------------------|-----|-------------|------|
| `adc_buf[0]` | PA0 | IN1 | 最左 |
| `adc_buf[1]` | PA1 | IN2 | 左中 |
| `adc_buf[2]` | PA3 | IN4 | 右中 |
| `adc_buf[3]` | PB0 | IN11 | 最右 |

DMAは循環モードで動作し、バッファを自動的に更新し続けます。メインループでADCを手動トリガーする必要はありません。

### モータードライバー（TB6612または同等品）

| モーター | 方向ピン 1 | 方向ピン 2 | PWMピン | タイマーチャンネル |
|---------|-----------|-----------|--------|----------------|
| 左ホイール Motor A | AIN1 = PF0 | AIN2 = PF1 | PA8 | TIM1_CH1 |
| 右ホイール Motor B | BIN1 = PB1 | BIN2 = PA10 | PA9 | TIM1_CH2 |

**PWMパラメータ**：TIM1、プリスケーラ 32、周期 1000 → 周波数 = 8MHz / 32 / 1000 = **250 Hz**。CCR 範囲 0〜1000 がデューティ比 0%〜100% に対応。

## 初期化順序（`main` 関数の `USER CODE BEGIN 2`）

```
HAL_ADCEx_Calibration_Start()   ← DMA開始より前に必ず実行
HAL_ADC_Start_DMA()             ← 連続取得を開始
HAL_TIM_PWM_Start(CH1)          ← 左ホイール PWM 出力を有効化
HAL_TIM_PWM_Start(CH2)          ← 右ホイール PWM 出力を有効化
```

> **注意**：CubeMX が生成したコードに 3 つのバグが存在していたため、`main.c` で修正済みです：
> 1. `adc_buffer` と `adc_value` は別々のバッファであり、DMA が異なるアドレスを指して 2 回起動されていた
> 2. ADC キャリブレーションが `HAL_ADC_Start_DMA` の後に呼ばれていた（順序が誤り）
> 3. `HAL_ADC_Start_DMA` が 2 回呼ばれていた

## ライントレース ステートマシン

### センサー二値化

```c
uint8_t s = (adc_buf[i] > BLACK_THRESHOLD) ? 1 : 0;
// 1 = 黒線を検出、0 = 白い地面
```

4 センサーの状態を 4 ビット値 `[sL  sML  sMR  sR]` としてエンコードします：

```
sL   sML   sMR   sR
PA0  PA1   PA3   PB0
左                  右
```

### 判定テーブル

| 状態（2進数） | 意味 | 左PWM | 右PWM | 動作 |
|-------------|------|------|------|------|
| `0110` `0111` `1110` `1111` | 中央 | 650 | 650 | 直進 |
| `0010` `0011` | ラインが右へずれ | 850 | 150 | 右旋回 |
| `0001` | ラインが大きく右へ | 850 | −500 | 急右旋回 |
| `0100` `1100` | ラインが左へずれ | 150 | 850 | 左旋回 |
| `1000` | ラインが大きく左へ | −500 | 850 | 急左旋回 |
| `1001` | T字路 / ライン終端 | 650 | 650 | 直進維持 |
| `0000` | ライン消失 | 325 | 325 | 低速直進（ライン再検出待ち） |

## 調整可能パラメータ（`main.c` 冒頭のマクロ定義）

| マクロ | デフォルト値 | 説明 |
|--------|------------|------|
| `BLACK_THRESHOLD` | 2000 | ADC閾値（0〜4095）。この値より高い = 黒線 |
| `SPEED_BASE` | 650 | 直進速度 |
| `SPEED_FAST` | 850 | 旋回時の外側ホイール速度 |
| `SPEED_SLOW` | 150 | 旋回時の内側ホイール速度 |
| `SPEED_SPIN` | 500 | 急旋回時の逆転ホイール速度 |

## トラブルシューティング

### ロボットが逆方向に曲がる
`Motor_Drive` 呼び出しの 2 つの引数を入れ替えるか、`Motor_Drive` 関数内で該当モーターの `xIN1`/`xIN2` ロジックを反転させてください。

### センサーの極性が逆（白い地面で高いADC値を返す）
`main.c` の比較演算子を `>` から `<` に変更してください：

```c
// 変更前
uint8_t sL = (adc_buf[0] > BLACK_THRESHOLD) ? 1 : 0;
// 変更後
uint8_t sL = (adc_buf[0] < BLACK_THRESHOLD) ? 1 : 0;
```

### 速度が速すぎてコースアウトする
`SPEED_BASE` を下げ、`SPEED_FAST` も同じ比率で下げてください。

### ライン消失後に復帰できない
`case 0x00` ブランチの低速直進速度を上げるか、最後の旋回方向を記憶するロジックを追加してください（前回の `st` を変数に保存し、`st == 0` のときにその動作を繰り返す）。

## さらなる改善案

- **PIDコントローラー**：ステートマシンを加重誤差 `e = −3·sL − 1·sML + 1·sMR + 3·sR` に置き換え、P項とD項でトレース精度と振動を改善する
- **動的閾値設定**：起動時にセンサーの最大・最小値をスキャンして中間閾値を自動計算し、異なる照明環境に対応する
- **TIM2**（初期化済み、1Hz周期）：定期的なデバッグ出力やウォッチドッグのフィードに利用可能
